Ok so you are happy with `no-orm` and now you want to push it live. How do you do that?

This guide will look at the [example server](https://github.com/william-coulter/no-orm-example-server/tree/main) and show you an approach to deploying to production.

## Containerisation

We will assume that you are deploying your server by containerising your code in some way.
